## Findings from the rule review

- **Old quote check.** The advice says to quote the decisive wording. The check also requires each numeric depth quote to be inside a depth evidence quote. OncoTrace #13 removed this check when it switched to quotes for each answer. #48 updates the YAML for that format. [Old check, lines 66–71](https://github.com/dsi-rse/clinic-2026-whitney-lab/blob/6bb73bb/tasks/endo_myometrial_invasion.yaml#L66-L71) · [Old advice, lines 278–289](https://github.com/dsi-rse/clinic-2026-whitney-lab/blob/6bb73bb/tasks/endo_myometrial_invasion.yaml#L278-L289) · [OncoTrace #13](https://github.com/dsi-rse/oncotrace/pull/13) · [PR #48](https://github.com/dsi-rse/clinic-2026-whitney-lab/pull/48)
- **Two specimen checks can pull in opposite directions for one submission.** Invasion marked `not_applicable` requires a non-hysterectomy specimen value. A definite depth requires `hysterectomy`. A submission with both values cannot meet both checks. The advice gives a way to answer consistently by using `not_applicable` for depth when there is no myometrium to assess. I found no confirmed contradiction for a valid answer in this pair.
