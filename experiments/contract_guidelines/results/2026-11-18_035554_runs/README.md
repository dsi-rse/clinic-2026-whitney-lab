- `offline_checks.csv`: one row per contract and check, made by script. `items` names the values or names found; report text is never written.
- `known_gaps.csv`: hand scores from `inputs/gap_scores.csv` (1 fixed, 0.5 partly, 0 not), summed. The reasons are in that file.
- `agreement_per_run.csv`: per run and field, patients out of the scored roster: correct, wrong, over-committed (a definite answer where the annotation says not applicable or cannot be determined) and abstained (no answer).

- `baseline_commonest.csv`: what always answering the commonest annotation scores.
- `refusals.csv`: OncoTrace's refusals by rule signature, per run.
- `outcomes_per_patient.csv`: per field and patient, the annotation, then each run's answer and outcome (correct, wrong, over_committed, abstained; no_score for a server error).
- `changes_vs_old.csv`: per arm and field, patients `better` (correct in each of the arm's runs, in neither `old` run) and `worse` (the reverse), with their IDs; `same_in_all_runs` counts patients with one outcome across all runs.
